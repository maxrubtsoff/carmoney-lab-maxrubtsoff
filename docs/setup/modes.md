# Режимы Kilo: ask vs code

Промпт: «В README не хватает раздела «Как проверить, что сервис жив». Разберись по
Makefile и docker-compose.yml, какие команды для этого есть, и добавь такой раздел
в README.»

- **ask** — прочитал `Makefile` и `docker-compose.yml`, ничего не изменил (файлы
  репозитория остались нетронуты). Дал готовый текст раздела прямо в чате и явно
  написал, что не может редактировать файлы в read-only режиме.
- **code** — получил тот же промпт и сам отредактировал `README.md`, вставив раздел
  «Как проверить, что сервис жив». Окна с предпросмотром диффа/подтверждением перед
  записью не было — правка применилась сразу.
- Для разбора и анализа кода без риска случайных правок возьму агента **ask**: он
  безопасен, когда нужно просто понять код или подготовить текст, не трогая файлы.
