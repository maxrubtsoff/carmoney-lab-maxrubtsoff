## Замечания по сессии 1

- Первая команда провалилась: агент написал `cd ... && dir`, а в Windows PowerShell `&&` не работает. Дальше он сам перешёл на другой синтаксис.
- Перед скриншотом агент написал, что в интерфейсе будет «4 лет». Это возраст из его curl с `year: 2022`. В форму он потом ввёл 2019, и на скриншоте 7 лет. Код и скриншот согласованы, неточен только промежуточный прогноз.
