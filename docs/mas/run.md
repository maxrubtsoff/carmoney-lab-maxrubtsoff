## Допущения, непроверенное, риски

- **Решения человека** B1–B6 — в [`analyst.md`](analyst.md). Пустой `applicant_ref` = аноним, не строка / > 32 символов = 422 — допущение координатора в духе B3.
- **НЕ ПРОВЕРЕНО на рабочей базе `carmoney_lab`**: миграция `db/migrations/001_active_applicant_unique.sql` останавливается на реальном дубле `CL-0025` (id 29, 30 — следы e2e-проверки 2.1.3). Нужно закрыть одну заявку (`POST /api/applications/30/cancel`) и повторить миграцию. Все проверки шли на копии `carmoney_check` и на свежей базе из `schema.sql`.
- Тесты требуют живую MySQL; `make` и PHP локально не установлены — запуск через `docker compose exec`.
- `composer.lock`: content-hash пересчитан вручную (packagist недоступен из контейнера), сверен `composer validate --strict` и независимым пересчётом.
- Вне объёма: кнопки отмены во фронте нет; `/cancel` без авторизации (её нет во всём сервисе); retry при deadlock; `01` в id отмены адресует заявку 1.
- Приёмка человеком не проводилась.
